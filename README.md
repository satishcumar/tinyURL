# tinyURL

A Spring Boot URL-shortening service used as the working application for an agentic SDLC orchestration case study.

## Baseline capabilities

- Create short URLs
- Redirect using short codes
- Record redirect analytics
- Persist mappings with H2
- Validate requests and return structured API errors
- Run unit and controller tests through Maven CI

## Case-study scenarios

- [Greenfield: Custom URL Aliases](docs/scenarios/greenfield-custom-alias.md)

The greenfield scenario documents requirement normalization, dependency-aware decomposition, parallel agent execution, approval gates, validation, dynamic re-planning, failure controls, auditability, and release readiness.
